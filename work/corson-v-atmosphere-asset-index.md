# Corson V atmosphere archive index (read-only)

Scope: indexed `d\atmosphere` and the configuration archive only; local build 23987138. No game/native/source/install files changed.

## Archive format and limits

`d\atmosphere` is a DSAR; the preserved DSAR unpacker yields 77,606,912 bytes. The current TOC maps 95 entries to archive index 3 (`d\atmosphere`). Each mapped record starts `1TAD` and uses a custom 0x21D5E72C header with section triples; its sections are not the generic config sections consumed by `inspect_photo_config.py`. Therefore the reflected `AtmosphereDef`/`FogSettingsDef` byte offsets are not applicable to these built-file bytes. The generic typed-config parser scanned 1,845 records in `d\config` but found no `Atmosphere*`, `Fog*`, or `Weather*` types.

The readable strings identify these as `Atmosphere Built File` records, but the embedded paths are mostly sky models/textures and associated assets. This index does not expose numeric fog settings such as `ColorMapDepthRange`, `NearDistance`, or `FarDistance`; no safe field values can be reported from it.

## Scene-name search

The readable path strings inside the 95 indexed records were filtered to NUL-terminated asset paths and known file extensions; incidental strings inside binary sections were excluded. No path in this index names Corson, the Emperor, the plaza, or the city. Nine `Nefarious` path hits are sky-texture references under `textures/sky/Neo_Nefarious/neo_nef_sky_*` (night variants and a marketing-cover texture). They establish that Nefarious sky resources are present, but do not identify the active Nefarious City atmosphere or its fog values.

The `d\\config` parser does recover unrelated Nefarious City / Emperor references, but its 1,845 successfully parsed built-config records contain no `Atmosphere*`, `Fog*`, or `Weather*` type. The indexed config data therefore supplies no matching scene atmosphere record in this pass.
